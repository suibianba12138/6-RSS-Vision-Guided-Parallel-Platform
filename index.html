01 / ABSTRACT

Abstract

This project explores a vision-guided six-actuator parallel platform built around a PC-side perception and control pipeline and an ESP32-based servo interface. RealSense RGB-D streams feed two separate OpenCV experiments: laser-target localization and black-rectangle geometry extraction. Their corresponding Python controllers generate pose or trajectory commands, which are passed to the InK6RSS inverse-kinematics interface and transmitted over serial to six servo channels.

The repository documents the hardware–software integration and the evolution of several controller experiments. It is an educational engineering prototype: source-level interfaces are available, while calibrated end-to-end performance and repeatable hardware benchmarks have not been established.

05 / SCOPE AND LIMITATIONS

Engineering prototype, not a validated control package.

The public source documents integration intent and implemented module boundaries. End-to-end hardware execution has not been independently revalidated for this showcase, and no quantitative claims are made for tracking accuracy, latency, stability or trajectory performance.

Camera-to-platform coordinates and depth-to-displacement conversion require calibration. The repository contains historical controller variants, and the native inverse-solver DLL requires provenance and licensing review. Servo limits, mechanical interference, power and emergency-stop behavior must be checked before hardware operation.
